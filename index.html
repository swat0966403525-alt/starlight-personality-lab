ABOUT THIS PROJECT

使用說明與隱私政策

測驗定位

本網站提供成人偏好、角色扮演想像、互動模式與親密關係需求的自我探索題目，並非經過臨床驗證的心理量表。

匿名與資料處理

網站不要求註冊、姓名、電子郵件或電話。測驗紀錄可選擇保存在本機瀏覽器；下載結果圖片只會在你的裝置上產生。

安全與同意

任何親密互動都應建立在成年人、自願、知情同意、可隨時停止及尊重界線的基礎上。測驗結果不應用來替他人貼標籤或施加壓力。

如何發布

將本資料夾中的 index.html、style.css、app.js 一起上傳至 GitHub 儲存庫，並在 Settings → Pages 選擇部署分支，即可發布為靜態網站。
